# 阿里云部署计划（草案）

本文件用于验证 fork 的提交与推送流程，并记录首期部署需求；不代表部署或性能测试已经完成。

## 首期目标

- 先测试一个直播间，启用弹幕烧录、语音字幕和自动切片。
- 后续支持增加直播间，按房间隔离配置、数据目录和数据库。
- 云资源及 API 月预算暂按约 1,000 元规划，实际费用以购买页及账单为准。

## 待验证的部署方案

- 阿里云 ECS：4 vCPU、8GB 内存，Ubuntu 22.04 LTS（x86_64）。
- 60GB 系统盘、200GB 数据盘、10Mbps 固定公网带宽。
- 使用 Docker Compose，持久化视频、日志、数据库和登录状态。
- 语音识别计划接入阿里云百炼 Paraformer；该适配尚未实现。
- 根据实际渲染耗时、上传积压和磁盘占用决定后续扩容。

## 上线验收

- 验证录制、弹幕与字幕同步、切片和投稿的完整流程。
- 验证容器重建后登录状态与待处理任务能够恢复。
- 连续运行 48 小时，确认处理及上传积压不会持续增长。
- 管理页面仅通过受限访问方式开放，不直接暴露到公网。
